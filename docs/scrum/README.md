# Evidencia de Scrum

Esta carpeta sostiene los 7 puntos de "Aplicación de Scrum" de la rúbrica. La evidencia
se produce **mientras se trabaja**, no se reconstruye la noche antes: las fechas de los
comentarios se ven.

## Qué va acá

- `sprint-N-planning.md` — qué se comprometió el equipo y con cuántos puntos
- `sprint-N-review.md` — qué se demostró, qué aceptó el Product Owner y qué se rechazó
- `sprint-N-retro.md` — qué salió bien, qué no, y **la única acción** para el sprint siguiente
- `capturas/` — el tablero al inicio y al final de cada sprint

## Dailies

No van acá: van como comentario diario en la issue fija **Bitácora del equipo**, con
este formato:

```
**Daily — AAAA-MM-DD**
| Integrante | Ayer | Hoy | Bloqueos |
|---|---|---|---|
```

Al cerrar el proyecto, esa issue exportada a PDF es el anexo de minutas.
